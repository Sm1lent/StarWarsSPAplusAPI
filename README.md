# Star Wars episodes

## Суть проекта
Без сторонних скриптов реализовано SPA(single page application) с двумя "страницами": страница со списком фильмов Звёздных Войн и страница фильма из списка на первой странице.
Контент обеих страниц составляется с использованием данных, получаемых при помощи запросов к https://swapi.dev/
Проект реализован на ванильном JavaScript без сборщиков и не требует сборки.
